# apps/console Docs

Read current console documentation in this order:

1. [`AGENTS.md`](../AGENTS.md) for scope and operational boundaries.
2. [Root repository map](../../../docs/repo-map/README.md) for cross-app ownership.
3. [Scoped project map](project-map.md) for console task routes and reuse owners.
4. [Root `DESIGN.md`](../../../DESIGN.md) and [console UI contract](design-system.md)
   for shared semantics and console composition.
5. `architecture.md` or `deployment.md` only for the selected backend/deployment
   boundary.

Source and current command output remain proof. Historical branch, worktree,
database, environment, and deployment snapshots are intentionally not maintained
as current facts here.
